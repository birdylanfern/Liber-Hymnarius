# Classification review

The 75 newly assigned category headers were inferred from unanimous categories on existing entries within two printed pages. They are **provisional**, not individually verified against the 1983 printed book. No liturgical hours were inferred.

`data/classification-review.json` lists each assignment, evidence page numbers, and the 82 remaining unclassified entries. The GABC music itself was not modified.

Further manual review is required for category boundaries, hymn variants, liturgical hours, and the remaining unclassified entries. The existing `npm run reconcile:gregobase` is not a substitute for this review.
