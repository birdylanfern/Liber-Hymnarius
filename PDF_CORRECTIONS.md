# Corrections against the 1983 Liber Hymnarius PDF

The old automatic slot filler reused unrelated GABC scores in empty hours. It is now disabled. Missing slots remain visible and unfilled instead of displaying wrong music. Existing source GABC scores are retained.

Explicit title-and-page hour corrections: **11**. Page-only suggestions held for review: **65**. Original indexed scores: **451**.

Corrections are listed in `data/pdf-corrections.json`. This is not a full page-by-page verification of every score or the entire printed edition.
