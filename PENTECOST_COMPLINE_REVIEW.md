# Pentecost Compline — source reconciliation

The printed Liber Hymnarius (1983), p. 97, gives **Iesu redemptor saeculi** for Compline at Pentecost. The imported collection already has **gb-15084.gabc**, indexed for Eastertide Compline on p. 77.

A separate catalogue reference has been created for Pentecost Compline, reusing that existing transcription. **UNCHECKED** means the melody has **not** been compared note-by-note to p. 97. The GABC source file is preserved. This is one provisional musical placement, not a verified new score.
