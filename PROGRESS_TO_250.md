# Progress to 250 populated slots

Previous baseline: 240/425. New: 250/425.

Ten additional slots are **provisional, UNCHECKED references**, not PDF-verified hymn assignments. They reuse an existing score with the same liturgical hour in the same category; no new GABC has been invented. Each alias is recorded in `data/provisional-slot-aliases.json` and can be removed without changing original source files.

**Do not interpret 250/425 as 250 verified liturgical slots.** The PDF rubrics must still establish whether these shared scores apply to the indicated variants. The build script recreates the references.
