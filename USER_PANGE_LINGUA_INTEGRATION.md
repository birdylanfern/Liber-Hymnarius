# Holy Week Office of Readings: Pange lingua

User supplied six complete stanzas plus a concluding Amen in Mode I. Stored verbatim in `gabc/hymns/pange-lingua-proelium-user-supplied.gabc` and assigned to `hebdomada-sancta / ol` (Liber Hymnarius printed pp. 61-63). The chant is **provisional**: notes and text have not been individually checked against the scan. Do not describe this as a verified 1983 transcription. Structural smoke tests passed; rendering in a Windows browser was not tested.

The user text includes markup inside two syllables and an unusual `A(ded)men.(cd)` ending; these are retained exactly pending score comparison.
