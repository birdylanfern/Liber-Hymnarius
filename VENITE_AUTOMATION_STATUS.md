# Automatic Venite for existing invitatories

This update opens the locally available Psalm 94 notation automatically for existing invitatories whose antiphon mode is IV, V, or VI. The two previously documented printed references remain explicitly identified. Other mode-matched selections are **provisional previews**, not certified liturgical pairings; the user may change or hide the score.

The site includes 49 invitatory antiphon entries (not necessarily 49 distinct liturgical slots). Only Psalm 94 settings IV*, V, and VI are locally available, so automatic *correct* notation for all invitatories is **not yet achieved**. The remaining modes, including unusual mode labels, retain the psalm text but do not receive an invented melody. This report does not assert that the available setting matches the book merely because the mode number matches.

Verification remaining: examine every printed invitatory cross-reference, source or transcribe the other Psalm 94 tones, and compare each pairing note-for-note against the printed 1983 Liber Hymnarius. Existing music files and source metadata were not changed.
