# Invitatory Psalm 94 source review

The three previously reported unindexed GABC files are not missing hymns: they are complete Psalm 94 notation sources (tones IV*, V, and VI) in `gabc/common/`.

The invitatory detail view now offers links to each of these source scores, explicitly labelled as unverified pairings. It retains the existing text-only Psalm 94 fallback. This change does not automatically select a tone, render it beneath the antiphon, or assert the correct pairing. Those tasks require checking each antiphon's printed psalm-tone rubric.

The source-integrity audit now tracks auxiliary Psalm scores separately from unindexed hymns. No GABC notation was modified. Coverage remains 334/429 populated slots, 95 empty.
