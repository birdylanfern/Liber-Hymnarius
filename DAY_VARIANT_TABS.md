# Sunday / weekday hymn tabs

Hymns with the same base incipit, liturgical section, and hour, where one score is explicitly marked `in dominica` / `in officio dominicali` and another `in feriis` / `in officio feriali`, are displayed as one hymn with two switchable tabs.

The tab changes the loaded GABC score, source attribution, and UNCHECKED warning as appropriate. Both original files and their direct links remain available. The catalogue index is not rewritten.

Other hymns with identical titles are intentionally not merged unless the Sunday/weekday pairing is explicit. Existing provisional placements remain marked UNCHECKED.
